## 如何运行示例

仓库中的示例以 `.cpp` 源文件为主，可以使用 Visual Studio、VS Code 或其他支持 C++ 的开发环境打开并运行。

使用 GCC 或 Clang 时，可以在对应示例目录中执行：

```bash
g++ -std=c++17 test.cpp -o test
./test
```

Windows PowerShell 中运行编译结果：

```powershell
g++ -std=c++17 test.cpp -o test.exe
.\test.exe
```

部分示例包含多个源文件，编译时需要将相关 `.cpp` 文件一起传给编译器。
